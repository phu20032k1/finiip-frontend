V112 BEHAVIOR
- Adds a dedicated Accounting item to the sidebar.
- Shows KPI cards using current backend data.
- Shows recent purchase/sales invoices and transactions.
- Provides workflow maps and feature lists per accounting module.
- Adds a persistent operational document panel to each accounting module.
- Users can create drafts, approve, post, cancel and delete documents subject to workflow rules.
- Posting collects debit/credit accounts and writes to the backend V112 ledger workflow.
- Adds extensible master-data management for each module.
- Adds accounting reconciliation/control-center UI.
- Sends module-specific review/analysis prompts to the existing Finiip AI chat.
- Links reporting workflow to the existing multi-file report engine.
- Gracefully warns when the V112 backend has not been deployed instead of fabricating persistence.
- Responsive layout for desktop/tablet/mobile.

SCOPE
V112 now provides a real shared persistence/workflow foundation for the broad accounting modules. Specialized industry workflows, licensed tax/e-invoice services, bank connections and one-to-one parity with every proprietary feature still require dedicated integrations and credentials; the UI does not pretend those external services exist when they are not connected.
