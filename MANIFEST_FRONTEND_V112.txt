V112 BEHAVIOR
- Adds a dedicated Accounting item to the sidebar.
- Shows KPI cards using current backend data.
- Shows recent purchase/sales invoices and transactions.
- Provides workflow maps and feature lists per accounting module.
- Sends module-specific review/analysis prompts to the existing Finiip AI chat.
- Links reporting workflow to the existing multi-file report engine.
- Provides AI-control alerts for draft, unpaid and low-confidence data.
- Responsive layout for desktop/tablet/mobile.

IMPORTANT LIMITATION
V112 is a functional accounting workspace/foundation, not literal 100% MISA feature parity yet.
The current backend does not yet have dedicated persistent ledgers/models for inventory, fixed assets, CCDC, payroll, costing, bank reconciliation, electronic invoice issuance, purchase/sales orders and contracts. V112 exposes these modules and connects them to AI/report workflows without fabricating persistence. These domains should be implemented as dedicated backend modules in subsequent versions.
